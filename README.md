# Навстречу

Пособие для тех, кто сейчас совсем один и хочет найти друзей или пару. Или хотя бы понять, нужно ли это.

Автор делает его на собственном опыте: сам проходит этот путь, записывает, что работает, и дописывает пособие по ходу дела.

## Что внутри

- **Путь.** Пять этапов по порядку, в каждом несколько небольших шагов:
  1. Посмотреть на себя честно
  2. Опора в себе
  3. Выйти к людям
  4. Из знакомых в друзья
  5. Искать пару

  Приложение показывает, какой шаг следующий, и сколько пройдено.
- **Дневник.** Записи о шагах, встречах, мыслях и выводах, с отметкой «как ты сейчас» и вопросами-подсказками. Через месяц по нему видно, что меняется.
- **Я.**
  - «Стоит ли?»: вопросы, чтобы понять, чего на самом деле не хватает и зачем тебе пара или друзья.
  - «Кого я ищу»: портрет пары и отдельно портрет друзей. В нём есть списки «обязательно», «было бы здорово» и «точно нет», темы, которые должны совпадать, и обратный вопрос: что ты можешь дать сам.
- **Места.** Где на самом деле знакомятся: общее дело, игры и разговорные клубы, волонтёрство, соседи и коллеги, онлайн. Для каждого места можно отметить «ещё нет», «разок» или «регулярно» и оставить заметку. Можно добавить свои места.

Все данные хранятся только в браузере на устройстве. Никакого сервера и никаких аккаунтов нет. В меню «⋯» можно сохранить копию данных и восстановить её, например, на другом телефоне.

## Как запустить

Сборка и установка не нужны.

- Проще всего открыть `index.html` в браузере.
- Или поднять локальный сервер в папке проекта и открыть http://localhost:8000:

  ```sh
  python3 -m http.server 8000
  ```

Чтобы приложение открывалось с телефона, папку можно выложить на любой статический хостинг: GitHub Pages, Netlify, Vercel. Потом в браузере телефона выбрать «Добавить на главный экран».

## Как устроен код

| Файл | Что в нём |
| --- | --- |
| `content.js` | Все тексты пособия: этапы и шаги, вопросы, места, подсказки для дневника. Править содержание нужно здесь. |
| `app.js` | Логика: экраны, сохранение, копия данных. |
| `styles.css` | Внешний вид, светлая и тёмная темы. |
| `index.html` | Точка входа. |

Если меняешь тексты в `content.js`, не трогай поля `id`: по ним сохраняется прогресс пользователя.

## Что можно сделать дальше

- Работа без интернета (service worker), чтобы приложение полностью вело себя как установленное.
- Мягкие напоминания: «в дневнике давно не было записей», «на этой неделе в клубе встреча».
- Планировщик недели: одно маленькое социальное действие на каждый день.
- График настроения по дневнику, чтобы видеть динамику за месяцы.
- Истории других людей, которые прошли этот путь (с их согласия).
- Когда-нибудь, возможно, знакомства внутри приложения. Для этого нужны сервер, модерация и серьёзная работа над безопасностью, поэтому это отдельный большой этап.
