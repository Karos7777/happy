# Навстречу

Пособие для тех, кто сейчас совсем один и хочет найти друзей или пару. Или хотя бы понять, нужно ли это.

Автор делает его на собственном опыте: сам проходит этот путь, записывает, что работает, и дописывает пособие по ходу дела.

## Что внутри

- **Путь.** Пять этапов по порядку, в каждом несколько небольших шагов:
  1. Посмотреть на себя честно
  2. Опора в себе
  3. Выйти к людям
  4. Из знакомых в друзья
  5. Искать пару

  Приложение показывает, какой шаг следующий, и сколько пройдено.
- **Дневник.** Записи о шагах, встречах, мыслях и выводах, с отметкой «как ты сейчас» и вопросами-подсказками. Через месяц по нему видно, что меняется.
- **Я.**
  - «Стоит ли?»: вопросы, чтобы понять, чего на самом деле не хватает и зачем тебе пара или друзья.
  - «Кого я ищу»: портрет пары и отдельно портрет друзей. В нём есть списки «обязательно», «было бы здорово» и «точно нет», темы, которые должны совпадать, и обратный вопрос: что ты можешь дать сам.
- **Места.** Где на самом деле знакомятся: общее дело, игры и разговорные клубы, волонтёрство, соседи и коллеги, онлайн. Для каждого места можно отметить «ещё нет», «разок» или «регулярно» и оставить заметку. Можно добавить свои места.

Все данные хранятся только в браузере на устройстве. Никакого сервера и никаких аккаунтов нет. В разделе «О приложении и данных» (на телефоне это кнопка «⋯» вверху) можно сохранить копию данных и восстановить её на другом устройстве.

## Телефон и компьютер

Это одно приложение для всех устройств (PWA):

- **На телефоне** внизу панель разделов, как в обычном мобильном приложении.
- **На компьютере** разделы в боковом меню слева, текст по центру. Запись в дневнике сохраняется по Ctrl + Enter (⌘ + Enter на Mac).
- Приложение **устанавливается** из браузера и потом **работает без интернета**.

Адрес приложения: https://karos7777.github.io/happy/

### Как установить

- **Android** (Chrome, Яндекс Браузер): открыть адрес, нажать «Установить» на плашке в приложении или в меню браузера выбрать «Установить приложение» / «Добавить на главный экран».
- **iPhone, iPad**: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Windows, macOS, Linux** (Chrome, Edge, Яндекс Браузер): открыть адрес, нажать «Установить приложение» в боковом меню или значок установки в адресной строке. Приложение появится в меню «Пуск» или в Launchpad и откроется в своём окне.

## Публикация сайта (GitHub Pages)

Нужно сделать один раз: **Settings → Pages → Build and deployment**. Там выбрать **Source: Deploy from a branch**, ветку с кодом и папку **/ (root)**, потом нажать **Save**. Через минуту-две приложение откроется по адресу выше. Дальше каждый push в эту ветку обновляет сайт сам.

Файл `.nojekyll` нужен, чтобы GitHub отдавал файлы как есть, без обработки.

## Как запустить у себя

Сборка не нужна. Можно просто открыть `index.html` в браузере, но тогда не будет установки и работы без интернета. Со всеми возможностями приложение работает через локальный сервер (http://localhost:8000):

```sh
python3 -m http.server 8000
```

## Как устроен код

| Файл | Что в нём |
| --- | --- |
| `content.js` | Все тексты пособия: этапы и шаги, вопросы, места, подсказки для дневника. Править содержание нужно здесь. |
| `app.js` | Логика: экраны, сохранение, копия данных, установка. |
| `styles.css` | Внешний вид: светлая и тёмная темы, раскладка для телефона и компьютера. |
| `index.html` | Точка входа. |
| `sw.js` | Service worker: кэширует приложение, чтобы оно работало без интернета. |
| `manifest.webmanifest`, `icons/` | Название, иконки и настройки установки. |

Если меняешь тексты в `content.js`, не трогай поля `id`: по ним сохраняется прогресс пользователя.

После изменения файлов приложения подними `VERSION` в `sw.js`. Тогда у тех, кто уже установил приложение, удалится старый кэш.

## План

1. **Сейчас.** Пособие для себя: путь, дневник, портрет, места. Работает на телефоне и компьютере.
2. **Проверка.** Пройти путь самому и дать попробовать нескольким людям. Понять, помогает ли это на самом деле.
3. **Знакомства.** Только если пункт 2 покажет, что приложение работает. Что для этого понадобится:
   - сервер и база данных (например, Supabase или Firebase);
   - аккаунты и анкеты;
   - подбор людей по портрету «Кого я ищу» и общим местам;
   - переписка;
   - безопасность: жалобы, блокировка, модерация, только 18+;
   - политика конфиденциальности и соблюдение законов о персональных данных.
4. **Google Play.** PWA можно упаковать в Android-приложение через Trusted Web Activity (инструменты Bubblewrap или PWABuilder), переписывать код не нужно. Что для этого понадобится:
   - аккаунт разработчика Google Play;
   - свой домен с файлом `.well-known/assetlinks.json`;
   - закрытое тестирование. Для новых личных аккаунтов Google сейчас требует его перед публикацией: не меньше 12 тестировщиков на протяжении 14 дней. Условия меняются, перед запуском стоит проверить актуальные.
